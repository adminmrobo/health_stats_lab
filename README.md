## 01편 구성

전임상부터 허가 후 4상까지의 관문을 곱셈 구조로 보고, 통과·탈락을 가르는 통계 판정 규칙을 익힌 다음, 분산을 모르는 작은 표본의 평균을 직접 계산해 봅니다. 마지막으로 AI를 넣으면 어느 자리가 단순해지고 어느 자리가 그대로 남는지를 가릅니다.

| 단계 | 다루는 것 | 직접 만지는 모형 |
|---|---|---|
| ① | 신약 개발과 임상시험의 전 과정 | 관문 통과 모형 — 후보가 어디서 줄어드나 |
| ② | 임상에서의 통계적 가설검정, 사건 수 기반 설계 | 판정 모형 — 효과 크기와 표본 수 |
| ③ | 분산을 모르는 작은 표본의 평균 추정 (t 분포 95% 신뢰구간) | 고리 던지기 모형 — 같은 방법으로 100번 추정 |
| ④ | 하위집단 함정·바탕 비율, 라벨 없는 탐색 | 다트 모형 · 서열 지도 모형 · 가린 자리 복원 모형 |
| ⑤ | 사전 정보 봉인 검증, AI 도입 단계별 분석 | 봉인 채점 모형 |

- 대결 주제: “팬데믹 초기 정보만으로 회피 변이를 앞서 지목할 수 있나” → 결과 **C(조건부)**, 판정 보류
- 페이지 끝에 검색 가능한 **지식 색인**(점 56개·관계 66개)과 **온톨로지·서지 꾸러미**(12개 파일 ZIP) 포함

## 숫자를 읽는 규칙

- 화면의 모의실험 수치는 모두 **시드를 고정한 설명용 모형**이며 실제 측정값이 아닙니다. 캔버스마다 `설명용 모형 · 실제 데이터 아님` 표시가 붙습니다.
- 문헌에서 가져온 수치만 각주 번호가 붙고, 바닥글 출처 표에 원문 링크가 있습니다.
- ③단계 예시는 Pagano·Gauvreau, *Principles of Biostatistics* 2판(Duxbury, 2000) 신뢰구간 장의 ‘Antacids and plasma aluminum level’ 예제이며, 단위 µg/L도 원 예제의 단위입니다.
- 참고문헌은 12건이고, 2차 자료는 기업 사례 자료 1건뿐입니다(각주에 그렇게 적었습니다). 나머지는 학술지 논문·기관 공식 글·교재입니다.
- 이 저장소의 자료는 교육용이며 의학적 판단이나 투자 판단의 근거가 아닙니다.
